# Contributing

1. Create a focused branch.
2. Run `npm run typecheck`, `npm run build`, and `npm run build:demo`.
3. Test permanent and primary dentition at desktop and 390 x 844.
4. Verify undo, JSON export, multi-select, bridges, missing teeth, bone loss,
   implants, crowns, direct crown/root zones, and quick diagnosis.
5. Do not add patient data, credentials, generated build output, or screenshots
   containing identifiable clinical information.
